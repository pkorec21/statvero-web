How to read this dataset

Prompt and completion tokens are summed. Tokenizers differ between providers, so a token is not an identical unit of text across all models. Models outside a day’s top 50 are aggregated as “other”; absence from the list is not zero usage. Lines connect recorded observations and do not fill missing dates.
